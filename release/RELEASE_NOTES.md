# ZONOE 软件源 2026092206

## 更新内容

本版本以 `source-v2026092205` 为升级基线，修复 IPA Data Center 在实际操作中暴露的软件源保存异常处理、测试按钮事件传播，以及解析暂停/清空时遗留 `parsing` 状态无法恢复的问题。该版本不改变在线更新协议，不新增数据库迁移，不自动修改 `fa_category` 或软件源目标数据库。

### 软件源保存与测试

- 软件源保存补齐缺失字段默认值与事务保护，减少 FastAdmin 表单提交异常导致的半写入状态。
- 保存/删除事务同时捕获 PHP 7.0 可用的 `Throwable`，失败时执行回滚并保留真实错误。
- 软件源“测试”按钮继续执行只读连接检查；显式阻止事件传播和同元素后续处理，避免点击测试时误选表格复选框。

### 解析暂停与清理

- 暂停解析后检查 Parse Worker 存活状态；仅在 Worker 已离线时回收遗留 `parsing` 任务。
- 孤立解析任务恢复为 `discovered`，保留 IPA 扫描记录并写入明确的回收原因。
- 若 Parse Worker 仍存活，当前正在处理的 IPA 继续允许完成，不强制中断。
- 清空全部解析结果前先回收无存活 Worker 的孤立任务，再检查是否仍有真实在处理的 IPA。
- 清空操作继续只删除解析结果、二进制索引、数据库比对结果和解析尝试记录；不删除 OpenList 扫描记录、软件源或 `fa_category`。

### 兼容性与验证

- PHP 7.0 语法检查通过。
- MySQL 5.7 既有 2026092205 迁移幂等检查通过；本版本无新增 SQL。
- Mach-O / FAT Mach-O / IPA bounded parser contract 均通过。
- IPA Online Update Release Gate 在 2206 修复分支上通过。

### 在线更新

继续沿用现有 `UpdateManager / UpdateInstaller`：ZIP 下载、SHA256 校验、备份、既有增量 SQL、文件覆盖、文件校验、版本写入和失败回滚逻辑均不改变。
