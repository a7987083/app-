# ZONOE 软件源 2026091611

## 更新内容

- 新增卡密用途模型，卡密时长（`kmyp`）与下载权限彻底分离：`1=全软件源授权`、`2=仅验证`、`3=指定App授权`。
- 旧卡密自动兼容：在线升级新增 `card_scope` 字段，默认值为 `1`，因此已经发行和已经激活的旧卡仍保持原来的“解锁全部付费App”行为。
- 新增“仅验证”卡：可以正常生成、激活、绑定 UDID、计算有效期并通过既有设备验证接口，但不会让软件源进入全局解锁状态，也不会暴露任何付费 App 的下载地址。
- 新增“指定App授权”卡：后台生成卡密时可搜索并多选当前启用且受锁保护的 App；同一张卡可授权一个或多个 App，未选择的付费 App 仍保持锁定。
- 软件源下载权限改为逐 App 判断：全软件源卡解锁全部付费 App；指定 App 卡只解锁其映射的 App；多张有效指定 App 卡的权限自动合并；验证卡不参与下载权限计算。
- 软件源公开协议保持兼容：服务器内部使用 `fa_category.id` 进行权限判定，但不会在 appstore/appstore_v2 公共 App JSON 中新增 `id` 字段。
- 新增 `fa_kami_app` 关联表保存 `kami_id -> app_id` 多对多授权映射，避免在卡密表中存逗号分隔 App ID。
- 授权叠加改为按权限链隔离：全源卡只和全源卡叠加；验证卡只和验证卡叠加；指定 App 卡仅在 App 集合完全相同时叠加，避免不同产品的有效期相互污染。
- 换绑逻辑同步升级为权限链隔离：提交验证卡不会把同一 UDID 上的全源卡一起迁移；指定 App 卡只迁移相同 App 集合的授权链；已过期的提交卡不能借用其他有效授权执行换绑。
- 管理后台卡密列表新增“卡密用途”列；生成/编辑页面新增用途选择和指定 App 多选控件。修改已激活卡的用途或 App 映射后，新的下载权限即时按服务器规则重新计算。
- 新增 PHP 7.0 回归测试，覆盖验证卡不解锁软件源、指定 App 下载权限、旧卡兼容、权限集合合并、权限链叠加和权限链换绑保护。
- 本版本包含数据库在线迁移 `2026091611_card_scope.sql`，GitHub 在线更新器会在覆盖程序前自动备份数据库并执行幂等迁移，无需手工修改 MySQL。

## 数据库迁移

- `fa_kami` 新增 `card_scope tinyint unsigned NOT NULL DEFAULT 1`。
- 新建 `fa_kami_app`，包含唯一约束 `(kami_id, app_id)` 及查询索引。
- 迁移脚本会检查字段是否已存在，可重复执行；非法/空用途值会归一为旧版兼容的全软件源授权。

## 兼容性

- 目标环境继续兼容宝塔 PHP 7.0 与 MySQL 5.7。
- 不改变现有卡密日/周/月/季/年时长定义，不改变已有卡密字符串格式。
- 不改变 appstore/appstore_v2、Nuosike 加密、黑名单等现有公共协议。
- GitHub 在线更新继续使用 HTTPS、SHA256、更新前数据库/程序备份、文件覆盖校验和失败回滚机制。
