# ZONOE 软件源 2026091706

## 更新内容

- 修复删除卡密后 `fa_kami_app` 仍残留“指定 App 卡授权映射”的问题。
- 修复删除 App 后 `fa_kami_app` 仍残留对应 App 映射的问题。
- 卡密仅到期不会删除映射；只有真正删除卡密时才同步删除 `kami_id` 对应映射。
- App 仅隐藏、停用或编辑不会删除映射；只有真正删除 App 时才同步删除 `app_id` 对应映射。
- 映射清理通过 ThinkPHP `beforeDelete` 模型事件执行，继续受 FastAdmin 原删除事务保护，批量删除同样生效。
- 修复清空“换绑记录”后授权总览仍显示旧预览的问题。
- 修复清空“授权事件”后授权总览仍显示旧预览的问题。
- 两类日志清空成功后直接跳回授权总览对应预览区，并附带唯一刷新参数。
- 授权总览响应增加 `Cache-Control: no-store` 等禁止缓存头，避免浏览器后退恢复清空前的旧 8 条预览。

## 数据库语义

- `fa_kami_app` 继续作为“指定 App 卡 -> App”的映射表。
- 本版本不改变表结构，也不自动删除历史到期卡的映射。
- 删除卡密时只删除该卡对应的 `fa_kami_app.kami_id` 映射。
- 删除 App 时只删除该 App 对应的 `fa_kami_app.app_id` 映射。
- 已存在的孤儿映射仍可通过“数据完整性”页面审计，本版本不进行未经确认的历史数据批量清理。

## 兼容性

- 不改变全软件源、仅验证、指定 App 三种卡密含义。
- 不改变卡密一次性消费、授权叠加、换绑额度、`apiface` 签名和续费入口协议。
- 兼容 PHP 7.0 / MySQL 5.7。
