# ZONOE 软件源 2026091806

## 更新内容

本版本修复 2026091805 上线后发现的两个问题。

### 1. 动态公告授权时间优先级

新增通用动态变量：

- `[到期时间]`
- `[剩余时间]`
- `[部分到期时间]`
- `[部分剩余时间]`

通用授权时间严格按以下优先级选择：

1. 全软件源授权
2. 指定 App 授权
3. 仅验证授权

当存在“部分App授权”时，不再出现“授权状态有值、到期时间/剩余时间为空”。

指定 App 授权存在多张有效卡时，部分授权状态使用最晚有效到期时间。

在线更新会自动把公告配置中的：

- `[全源到期时间]` → `[到期时间]`
- `[全源剩余时间]` → `[剩余时间]`

无需手工修改已有公告。

### 2. 授权查询页面兼容入口

保留原 ThinkPHP 路由：

- `/license`

并新增等价入口：

- `/authorization`

当前生产服务器的 `/license` 被 Nginx 的大小写不敏感 LICENSE 安全规则在 PHP 之前拦截，因此单纯在线更新 PHP 文件无法覆盖正在运行的 Nginx vhost 配置。

2026091806 将 API Center 的“授权查询”地址改为 `/authorization`，在线更新后可直接使用该地址访问同一个授权查询页面。

原 `/license` 路由继续保留；以后修正生产 Nginx 规则后无需再次修改程序。
