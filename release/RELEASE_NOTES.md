# ZONOE 软件源 2026092205

## 更新内容

本版本以 `source-v2026092204` 为升级基线，集中修复 IPA Data Center 在线实际使用中暴露的 FastAdmin 表单交互、软件源测试误选、解析暂停/恢复和批量清理控制问题；不改变原在线更新协议，不自动修改 `fa_category` 或软件源目标数据库。

### FastAdmin 表单与软件源交互

- OpenList 数据源表单补齐 FastAdmin 原生 `role=form`、validator、POST action 约定，保存成功后按原生表单流程处理，避免空错误提示和需要手动刷新。
- MySQL 软件源新增/编辑继续使用 FastAdmin `Form.api.bindevent`。
- 软件源“测试”按钮阻止事件冒泡，点击测试连接不再自动勾选表格左侧复选框。
- 软件源测试仍只执行只读连接检查，不修改目标数据库。

### 解析控制

- 新增“暂停解析 / 继续解析”按钮。
- 暂停解析只阻止后续批次领取新的 IPA；已开始的当前 IPA 允许完成，避免产生半解析状态。
- 新增“清空全部解析结果”操作；执行前必须先暂停自动解析，并确认不存在正在解析的 IPA。
- 清空操作会删除 IPA 的数据库比对结果与二进制索引，并把已解析/解析失败项重新设为“待解析”。
- 清空操作保留 OpenList 扫描发现的 IPA 文件记录、数据源和 `fa_category`，不会删除软件源目标数据库记录。
- 解析尝试额度历史同步清空，使重新解析从新的额度窗口开始。

### 权限与数据库迁移

- 新增 MySQL 5.7 幂等迁移：`release/sql/2026092205_ipa_ui_controls_hotfix.sql`。
- 为保存解析设置、暂停/继续解析、清空解析结果、数据源删除/强制删除、重新解析、异常详情、重新比对和人工字段写回补充 FastAdmin 权限节点。

### 在线更新

继续沿用现有 `UpdateManager / UpdateInstaller`：ZIP 下载、SHA256 校验、备份、执行增量 SQL、覆盖程序、文件校验、版本写入和失败回滚逻辑均不改变。
