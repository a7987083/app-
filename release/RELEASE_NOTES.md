# ZONOE 软件源 2026091607

## 更新内容

- Phase 15.3 重构“更新运维中心”扫描引擎：页面不再用 PHP 递归 `scandir/filesize/filemtime` 阻塞扫描，改为后台 PHP CLI worker 调用系统 GNU `find` 扫描网站根目录。
- 新增持久化储存索引 `runtime/storage/index.json`：打开运维中心直接读取上一次完成的索引，页面可秒开；首次无索引时自动启动后台扫描。
- 新增源码目录快速指纹：`application`、`vendor`、`thinkphp`、`extend`、`addons`、`public/assets`、`public/static` 使用“相对路径 + 文件大小”的 SHA256 目录指纹；与上次索引一致时整棵目录跳过详细扫描，直接复用统计结果。
- 系统扫描使用 `find -xdev`，不跨文件系统、不跟随符号链接；文件元数据由系统一次输出路径、大小、mtime、inode，PHP 仅做分类与汇总。
- “重新扫描全站”改为非阻塞后台任务，并新增扫描进度条：显示阶段、百分比、已处理/总文件数和完成状态；前端每秒轮询轻量 status-only API。
- “执行自动安全清理”改为非阻塞后台任务，并新增独立进度条：显示候选总数、已处理数量、删除数量和已释放容量；清理完成后自动重新建立储存索引。
- “预览自动安全清理”不再重新扫描全站，只读取上一次索引生成的安全候选列表，因此可以快速返回。
- 最大文件 TOP 50 改为扫描过程中分批截断，不再把全站全部文件长期保存在 PHP 数组后再统一排序。
- 保持原有安全规则：程序文件、`public/uploads/` 业务数据、日志、更新状态、符号链接和路径穿越仍受保护；备份/未知文件只允许人工确认删除。
- 新增 PHP 7.0 合约与运行时测试，覆盖 GNU find 扫描、缓存索引、扫描 100% 进度、源码目录指纹复用及原 Phase 14/15 储存安全回归。

## 配置要求

- 推荐服务器提供 GNU `find`、`sort`、`sha256sum`，并允许 PHP 使用 `exec`、`proc_open` 以及同版本 PHP CLI；运维中心会显示当前是否进入“系统高速模式”。
- 如果系统命令能力被 PHP `disable_functions` 禁用，本版不会静默回退到原来的慢速全站 PHP 扫描，而会明确提示扫描引擎不可用，避免再次出现长时间卡死。

## 兼容性

- 目标环境继续兼容宝塔 PHP 7.0。
- 不修改数据库结构，不删除业务上传数据，不改变授权、卡密、黑名单、换绑、appstore/appstore_v2 与 Nuosike 兼容加密逻辑。
- GitHub 在线更新继续使用 HTTPS、SHA256、备份、文件校验和回滚机制。
