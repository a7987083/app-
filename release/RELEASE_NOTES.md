# ZONOE 软件源 2026091606

## 更新内容

- Phase 15.2 将“更新运维中心”升级为全站文件与储存管理器，递归扫描网站根目录全部普通文件，不再只统计 updater 自己的 backup/history/status/cache。
- 新增全站总文件数与总占用，并按“核心程序/发布资产、业务持久数据、可重建缓存、日志、备份/归档、临时文件、未识别文件”分类统计。
- `public/uploads/` 作为业务持久数据默认保护；application/vendor/thinkphp/extend/addons/public assets 等程序路径默认保护；更新任务状态、历史和锁文件默认保护。
- `runtime/cache/`、`runtime/temp/`、`runtime/tmp/` 以及明确临时扩展名文件进入自动安全清理；自动删除要求文件至少存在 1 小时，避免误删刚生成的临时数据。
- 所有 ZIP/TAR/GZ/7Z/RAR/SQL/BAK 等备份归档和未识别文件均纳入储存统计与“需人工确认”列表，但不会自动删除；管理员可逐项勾选后删除。
- 人工删除接口会在服务端重新分类路径，伪造请求也不能删除程序保护文件、用户上传、日志或更新任务状态；同时拒绝路径穿越和符号链接目标。
- 新增最大文件 TOP 50，便于快速定位真正占空间的文件。
- 保留更新历史、回滚、任务诊断和文件完整性检查；Phase 15.1 数据完整性审计功能保持不变。
- 新增 PHP 7.0 运行时回归：验证整站文件全部计数、上传文件保护、缓存安全删除、备份人工删除以及伪造受保护路径删除被拒绝。

## 兼容性

- 目标环境继续兼容宝塔 PHP 7.0。
- 不修改数据库结构，不删除业务上传数据，不改变授权、卡密、黑名单、换绑、appstore/appstore_v2 与 Nuosike 兼容加密逻辑。
- GitHub 在线更新继续使用 HTTPS、SHA256、备份、文件校验和回滚机制。
