# ZONOE 软件源 2026091610

## 更新内容

- 按运维需求移除“全站搜索 / 全站储存扫描”功能，不再递归扫描网站目录，也不再展示网站总占用、最大文件 TOP 50、备份/未识别文件人工删除等全站文件管理入口。
- 删除运维控制器中的全站扫描、全站状态轮询和任意候选文件删除 API；运维中心不再依赖 GNU `find`、PHP CLI worker、目录指纹或 `open_basedir` 兼容扫描层。
- 运维中心恢复为“在线更新系统专用运维”：仅统计更新备份、更新历史、任务状态、更新缓存、更新锁、最近升级/回滚和运行中/疑似中断任务。
- “安全清理”仅作用于在线更新器自身数据，并保留原有保护策略：运行中任务不删、仍被成功更新历史引用的回滚备份不删、只按保留期处理终态状态/历史/无引用旧备份。
- 在线更新包不再包含 `SiteStorageManager`、`FastStorageManager`、`FastStorageManagerCompat` 和 `tools/storage_worker.php`，后续版本不再维护该全站扫描链路。
- 新增 Phase 15.4 回归契约，强制验证全站扫描 API/UI/客户端调用均已移除，同时保留更新运维、预览清理、确认清理和 GitHub 在线更新能力。

## 兼容性

- 目标环境继续兼容宝塔 PHP 7.0。
- 不修改数据库结构，不改变授权、卡密、黑名单、换绑、appstore/appstore_v2 与 Nuosike 兼容逻辑。
- 不需要 `exec`、`proc_open`、GNU `find` 或 PHP CLI 才能打开更新运维中心。
- GitHub 在线更新继续使用 HTTPS、SHA256、备份、文件校验与回滚机制。
