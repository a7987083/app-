# ZONOE 软件源 2026091807

## 更新内容

本版本将动态公告的授权时间彻底收敛为一套逻辑，行为与参考方案一致。

### 统一授权时间

公告编辑器只保留：

- `[授权状态]`
- `[到期时间]`
- `[剩余时间]`

底层仍保留全软件源、指定 App、仅验证三种权限，但公告层不再暴露三套独立时间。

当前有效授权按以下优先级选择：

1. 全软件源授权
2. 指定 App 授权
3. 仅验证授权

选中当前有效授权后：

- `[到期时间]` 显示该授权的到期时间
- `[剩余时间]` 显示该授权的剩余时间

如果没有购买过有效解锁码，或所有解锁码均已到期：

- `[授权状态]` = 已过期或未解锁本源
- `[到期时间]` = 已过期或未解锁本源
- `[剩余时间]` = 已过期或未解锁本源

### 旧模板自动兼容

在线更新会自动迁移旧公告变量：

- `[全源到期时间]`、`[部分到期时间]`、`[验证到期时间]` → `[到期时间]`
- `[全源剩余时间]`、`[部分剩余时间]` → `[剩余时间]`

带默认值的旧变量也会迁移。

即使 SQL 迁移被跳过，运行时仍会把旧变量映射到同一套通用授权时间，不会出现空白。

### 授权摘要

`[授权摘要]` 也改为单一时间模型，只显示：

- 授权状态
- 到期时间
- 剩余时间
- 部分 App 授权时附加指定 App 数量

不再分别列出全源、部分、验证三套到期时间。
