# ZONOE 软件源 2026092204

## 更新内容

本版本以 `source-v2026092203` 为升级基线，继续修复 IPA Data Center 在线上实际使用中暴露的软件源表单、解析调度、数据库比对和任务状态问题；不改变原在线更新协议，不自动修改软件源数据库。

### FastAdmin 原生表单与软件源

- 软件源新增、编辑、删除改回 FastAdmin 原生 Table/Form 流程，避免手写 AJAX 成功后仍弹空错误、删除后必须手动刷新等问题。
- 软件源测试连接保留只读测试动作，并显示明确失败原因。
- 密码编辑时留空继续保留现有密码，不回显数据库密码。
- 软件源仍支持优先级、启用/停用和“允许人工字段写回”；默认只读。

### 解析调度

- “解析设置”改为 FastAdmin `Form.api.bindevent` 标准表单提交。
- 解析执行改为 one-shot 批次调度：每次调度按后台配置领取有限数量 IPA，执行完成即退出，不再要求常驻 Parse Worker。
- 保留“每 N 分钟最多 N 个”、每小时上限、每日上限、失败冷却等控制。
- CLI 在领取 IPA 前预检 SecretBox/OpenList Token；服务器密钥缺失或解密配置错误时直接停止本轮，不再把 IPA 误标为 `parse_failed`。

### IPA 自动比对与异常预览

- IPA 解析成功后自动触发已启用软件源数据库比对。
- 异常详情首次打开时，如果当前 IPA 尚无比对记录，会主动执行一次比对；不再把“尚未比对”误报为“未配置软件源”。
- 异常详情继续显示数据库当前值与 IPA 建议值，并允许管理员人工勾选字段写回。
- 自动比对只产生差异结果；数据库写回仍必须由管理员显式确认。

### OpenList 扫描与删除

- Scan Worker 在领取扫描任务前完成加密 Token 预检。
- 目录扫描继续优先使用 `refresh=false` 和 `per_page=0`，不兼容时回退分页。
- 数据源删除允许先取消未执行/停滞任务再清理，不再被长期 pending 队列永久阻塞；真正正在处理的任务仍保留并发保护。

### 数据库

新增 MySQL 5.7 幂等迁移：`release/sql/2026092204_worker_source_hotfix.sql`，补充 FastAdmin 软件源新增/编辑/删除权限节点，并保留 2026092203 旧权限节点用于升级兼容。

### 在线更新

继续沿用现有 `UpdateManager / UpdateInstaller`：ZIP 下载、SHA256 校验、备份、执行增量 SQL、覆盖程序、文件校验、版本写入和失败回滚逻辑均不改变。

目标升级路径：`source-v2026092203 -> source-v2026092204`。
