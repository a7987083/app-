接入说明 展开 / 收起

当前选择：请选择已注册 Dylib

客户端接入
  1. 优先使用“概览 → OC 接入代码”自动生成配置。
  2. 客户端按 permissions、app_update、notice 消费服务端结果。
  3. Bootstrap 只负责发现最新 API；旧 endpointURL 保留为最终兜底。

运行配置：GET /index/dylib_verify/config?dylib_key=...

在线验证：POST /index/dylib_verify/verify

Protocol v2 HMAC 原文
udid\nbundle_id\ndylib_key\ndylib_version\ndylib_build\ndylib_sha256\ntimestamp\nnonce\nprotocol_version\napp_executable\napp_macho_uuid\napp_version\napp_build

协议说明仅用于调试和人工审计；日常生成 OC 代码无需手工填写这些字段。
