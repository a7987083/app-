2. 接入说明 （来自现有服务端控制器与 Objective-C 客户端协议）

当前选择：请选择已注册 Dylib

请求

POST /index/dylib_verify/verify，Content-Type: application/json

必填：udid、bundle_id、dylib_key、dylib_version、timestamp、nonce、signature

可选：dylib_build、dylib_sha256

HMAC-SHA256 原文顺序
udid\nbundle_id\ndylib_key\ndylib_version\ndylib_build\ndylib_sha256\ntimestamp\nnonce

使用该 Dylib 的验证密钥计算 HMAC-SHA256，发送小写 64 位十六进制 signature。

响应

ok、code、action、offline_grace_seconds、token、message、server_time

现有 iOS 客户端

clients/ios/ZONDylibVerify/ZONVerifyClient.h/.m

客户端明确使用上述 POST 接口；它不会替换旧的 Index::dylib() 或 Index::apiface()。

后台无法读取明文验证密钥。首次注册或主动轮换后，应把当次显示的密钥同步到对应客户端配置；不要从数据库密文反推。
