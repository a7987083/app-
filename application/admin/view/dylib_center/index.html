Protocol v3 流程
1. Client 生成/加载 P-256 Device KeyPair（私钥仅存在本机 Keychain）
2. POST /index/dylib_verify/challenge
   udid + dylib_key + device_public_key
3. Server 返回 challenge_id + challenge + expires_at
4. Client 对 v3 canonical body 做 ECDSA P-256 SHA-256 签名
5. POST /index/dylib_verify/verify
   App/Dylib identity + challenge + device_public_key + device_signature
   首次绑定额外提交 license_code
6. Server 验设备签名 → 黑名单/卡密/App Identity/版本/SHA256/权限
7. 返回短期 token + permissions + notice + app_update
客户端二进制中不存在 Verify Secret，也不存在其他全局共享对称密钥。
Runtime Config：GET /index/dylib_verify/config?dylib_key=...，响应由服务端 P-256 私钥签名；客户端使用生成代码内嵌的服务端公钥校验。
