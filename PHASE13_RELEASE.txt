更新内容：
1. 修复后台点击“后台解析 1 个”后当前 PHP-FPM 请求在 shutdown 阶段继续执行 IPA Worker，导致后台 Session 锁被长时间持有、刷新页面和其它按钮全部阻塞的问题。
2. Web 扫描/解析请求现在只负责写入 durable MySQL queue，绝不在 PHP-FPM shutdown handler 中消费任务；Persistent IPA Worker 是唯一后台消费者。
3. 新增 scripts/install-ipa-worker-service.sh，以 systemd 常驻运行 php think ipa:worker --sleep=2，Restart=always、开机自启。
4. 新增 application/admin/controller/IpaRuntime.php，同时检查 Persistent IPA Worker heartbeat 与 Persistent Parser Service RPC health。
5. IPA 元数据页新增运行时红色告警；Worker/Parser 任一异常时明确提示，并给出 sudo bash scripts/zonoe-server-bootstrap.sh 恢复命令。
6. 新增 scripts/zonoe-server-bootstrap.sh，服务器迁移/重装后统一恢复 Parser Service + IPA Worker，并验证 systemd active 与 Parser RPC health。
7. 修复元数据页刷新体验：刷新按钮显式重新请求服务端数据、显示“正在刷新/最后成功刷新/刷新失败”，解析后短期轮询列表状态。
8. 在线更新包包含 Runtime health controller、Worker installer、Parser installer 与统一 bootstrap 脚本。
9. 保留 2026091919 Persistent Parser Service、JSON scan snapshot、MySQL 5.7、OpenList HTTP E2E 与历史发布逻辑。

- tests/phase20_worker_contract_test.php 必须证明 IpaWorkerService 不包含 register_shutdown_function / fastcgi_finish_request inline worker fallback。
