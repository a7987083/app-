更新内容：
1. 已注册 Dylib 新增编辑、停用、启用、删除和接入说明入口；编辑时 Dylib Key 保持只读，避免破坏现有客户端签名/查找协议。
2. 停用仅修改 enabled=0，保留配置、版本、BundleID 授权和验证历史；服务端验证链继续只读取 enabled=1，停用后按既有 dylib_unknown / block 语义拒绝。
3. 删除采用引用保护：无版本、无 BundleID 授权、无验证历史时允许硬删；一旦产生业务历史则禁止删除并要求停用，避免审计记录和逻辑引用成为孤儿。
4. Dylib 管理页重排为“注册 → 接入 → 游戏授权 → 版本控制 → 验证记录”。
5. active/testing/deprecated/blocked/revoked、allow/disable_feature/show_message/block、result_code 等底层枚举保持不变，仅在 UI 做中文映射。
6. 接入说明来自现有 DylibVerify 控制器、DylibVerificationService 和 Objective-C ZONVerifyClient，接口仍为 POST /index/dylib_verify/verify，HMAC 字段顺序不变。
7. 验证记录将 result_code、action、UDID Hash、BundleID 等改为面向管理员的可读显示；底层日志字段和存储格式不变。
8. 删除使用项目现有 Layer.confirm 二次确认，所有写操作继续走 Fast.api.ajax / Backend 权限与既有 CSRF 机制。

在线更新：
- 目标升级：source-v2026092404 -> source-v2026092405。
- 不新增业务表结构或 SQL 迁移。
- PHP 7.0 / MySQL 5.7 兼容要求不变。
- 旧 Objective-C 客户端请求字段、签名顺序、版本规则和 BundleID 绑定行为不变。
- 在线更新继续沿用原 UpdateManager / UpdateInstaller，不改变下载、SHA256、备份、SQL 执行、文件覆盖、版本写入和失败回滚逻辑。
