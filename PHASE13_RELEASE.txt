ZONOE 软件源 Release 2026091802
版本：2026091802
基线：2026091801
阶段：Phase 19.2 — Legacy AppStore High Performance + Authorization Center Fix

更新内容：
1. 客户端继续只使用原 `/appstore`，无需支持 V3、无需修改软件源地址。
2. 新增 `SourceLegacyCache`，按 Guest / 全软件源 / 指定 App 权限集合隔离缓存，避免授权串数据。
3. `SourceAppRepository` 增加跨 worker generation，`SourceChangeLog` 保留 revision 并增加共享 revision 缓存，用于服务端缓存失效。
4. `AppStorePayload::apps()` 缓存大 App 列表映射结果；`SourceResponse::plainBody()` 缓存 Legacy 最终 JSON body。
5. 删除 `/appstore/v3/meta`、`/apps`、`/delta` 公网路由；`source_v3` 后台开关通过 SQL migration 删除；`fa_source_change` 保留。
6. 旧 `SourceV3.php` 在线更新后覆盖为 404 tombstone，`SourceSyncV3.php` 不再分发，避免旧安装继续暴露 V3。
7. 授权中心“换绑记录/授权事件”清空逻辑恢复 FastAdmin AJAX；清空后立即刷新，不再出现 1 秒自动跳转；授权总览不再保留陈旧页面数据。
8. `authorization.js` 纳入在线更新包；后台配置写入后主动失效软件源配置缓存。
