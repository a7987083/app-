更新内容：
1. App.php 在 JSON 构建完成后提前释放大型 payload/apps 数组，性能日志只保留 app_count，不再长期持有完整 payload。
2. App.php 在本地/远程加密完成后继续提前释放 JSON、encryptedResult 和 encrypted 临时引用，降低后半段峰值内存。
3. SourceResponse.php 为 PHP one-shot gzencode 增加默认 8 MiB 上限；超大响应跳过 PHP gzip，避免 body + compressed + zlib workspace 同时占用。
4. SourceResponse.php 在无 @@@ marker 时跳过无意义的大字符串替换扫描，同时保留原 marker 兼容行为。
5. SourceEncryptionProvider.php 的 appstore_v2 改为 header + payload 分段送入同一 codec state，去掉完整 container 副本；RC4/RSA/V2 wire protocol 不变。
6. 增加 payload release、gzip guard、V2 multipart codec 边界等价 contract，继续使用原 Phase 19.2 PHP 7.0 回归与在线更新包验证流程。
7. 不修改授权、downloadURL 裁剪、entitlement cache、Nuosike fallback、原 ZONOE Source Release workflow 语义。
