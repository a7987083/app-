ZONOE 软件源 Release 2026091610
版本：2026091610
基线：2026091609

更新内容：
1. 移除更新运维中心的全站搜索、全站储存扫描、最大文件 TOP 50、备份/未识别文件人工删除等全站文件管理功能。
2. 删除运维控制器的 scan、全站状态轮询、cleanupSelected 等全站扫描相关运行入口。
3. 运维中心仅保留在线更新系统自身的备份、历史、任务状态、缓存、更新锁、最近升级/回滚和运行任务诊断。
4. 安全清理恢复为 UpdateOps 保守清理，只处理更新器自己的终态状态、旧历史和无引用旧备份；运行中任务及被回滚历史引用的备份继续保护。
5. 正式在线更新清单不再包含 SiteStorageManager、FastStorageManager、FastStorageManagerCompat 和 storage_worker.php。
6. 新增 Phase 15.4 回归契约，验证全站扫描 UI/API/JS 已移除且更新运维核心能力仍可用。

兼容性：
- 兼容宝塔 PHP 7.0。
- 不需要 exec、proc_open、GNU find 或 PHP CLI 才能打开更新运维中心。
- 不修改数据库结构和授权数据。
- 不改变 appstore/appstore_v2、Nuosike 加密、UDID、卡密时长、黑名单和 transfer_count 语义。
- 保留 GitHub 在线更新、SHA256、备份、文件校验与回滚机制。
