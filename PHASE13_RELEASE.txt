更新内容：
1. Dylib 验证中心从 2408 的 7 个大区块平铺改为 5 个主入口：概览、版本、通知、验证记录、高级。
2. 概览集中 Dylib 基本信息、验证密钥、离线/失败策略、Dylib 列表与 OC 接入代码生成。
3. OC Codegen 固定渲染到概览 codegen-slot，不再动态插入一个新的编号大区块。
4. Codegen 默认只展示目标 Dylib、版本、预览和生成 ZIP；类前缀、最低 iOS、超时收进折叠“选项”；代码预览仅在执行预览后显示。
5. 远程通知独立到“通知”页签；版本独立到“版本”页签；验证日志独立到“验证记录”页签。
6. API Base URL、Bootstrap、Verify Path、游戏更新文案统一移入“高级”。
7. Protocol v2 / HMAC 接入说明与权限模型说明保留，但默认折叠，日常使用不再直接展示内部协议细节。
8. Bootstrap Table 在隐藏 Tab 打开后执行 resetView，避免隐藏容器初始化造成列宽异常。
9. 2409 不修改 Dylib 验证协议、HMAC canonical、Runtime Config 签名、权限计算、数据库结构、OC 生成结果协议。
10. 在线更新继续沿用既有 UpdateManager / UpdateInstaller；2409 无新增 SQL migration。
