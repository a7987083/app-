更新内容：
1. 以 source-v2026091918 为冻结基线前滚 2026091919，不覆盖任何历史 Release Tag/Asset。
2. IPA 解析从 PHP proc_open 每文件启动 Python，迁移为常驻 Python Persistent Parser Service；PHP 通过 loopback TCP RPC 调用，不再依赖 proc_open/exec/shell_exec/system/popen。
3. 保留成熟 scripts/ipa-range-info.py 的 HTTP Range、ZIP、binary plist、Mach-O、图标、mobileprovision、Framework/Dylib 等解析逻辑，不重写解析语义，PARSER_VERSION 保持 1，现有 MD5 parse cache 可继续复用。
4. 新增 scripts/ipa-parser-service.py，仅绑定 127.0.0.1/localhost，使用 newline-delimited JSON RPC，默认 tcp://127.0.0.1:19191。
5. Parser Service 检测服务文件或 ipa-range-info.py 被在线更新替换后自动 os.execv 自刷新；PHP RPC 客户端在自刷新窗口自动重试一次，未来更新无需依赖 PHP 进程启动权限。
6. 新增 scripts/install-ipa-parser-service.sh，一次性以 root 安装 systemd 单元，服务使用非 root 用户运行并设置 Restart=always、开机自启和基础 systemd sandbox。
7. 在线更新包包含 Parser Service 与安装器；由于 Web 更新器不拥有 root/systemd 权限，首次升级 2026091919 后需在服务器执行一次 sudo bash scripts/install-ipa-parser-service.sh。
8. 正式 parser contract 增加生产兼容验证：启动 Persistent Parser Service 后，以 disable_functions=proc_open,exec,shell_exec,system,passthru,popen 的 PHP 7.0 子进程验证 RPC health 成功，覆盖本次生产故障条件。
9. 1918 的 JSON scan snapshot、Persistent IPA Worker、MySQL 5.7、OpenList HTTP E2E、回滚与发布逻辑保持不变。
