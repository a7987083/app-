ZONOE 软件源 Release 2026091611
版本：2026091611
基线：2026091610

更新内容：
1. 卡密新增用途字段 card_scope：1=全软件源授权，2=仅验证，3=指定App授权；旧卡默认1，保持原行为。
2. 仅验证卡可以正常激活、绑定UDID和计算有效期，也可被既有设备验证接口识别，但永远不参与软件源付费App下载解锁。
3. 指定App卡可在后台生成/编辑时选择一个或多个已启用且受锁保护的App，只开放这些App的downloadURL。
4. 新增 fa_kami_app(kami_id, app_id) 多对多映射表；软件源协议本身不新增公开字段，App ID只在服务端内部用于权限判定。
5. 多卡权限可合并：多个指定App卡分别提供各自仍有效的App权限；有效全源卡存在时全部付费App可下载。
6. 授权时长按权限链独立叠加：全源/验证/指定App互不串联，指定App卡仅在App集合完全相同时叠加。
7. 自助换绑同步按权限链隔离，验证卡不会迁移全源卡，指定App卡只迁移相同App集合；过期提交卡不得借用其他授权换绑。
8. 卡密后台列表新增用途列，生成和编辑界面新增用途单选及指定App多选搜索。
9. 在线更新包包含 2026091611_card_scope.sql，自动新增card_scope和fa_kami_app；脚本幂等，可重复执行。
10. 新增Phase16 PHP7.0回归，覆盖旧卡兼容、验证卡隔离、指定App权限、权限叠加与换绑保护。

兼容性：
- 兼容宝塔 PHP 7.0、MySQL 5.7。
- 不改变现有日/周/月/季/年卡时长定义和卡密字符串格式。
- 不改变 appstore/appstore_v2、Nuosike 加密、黑名单等公共协议。
- 旧卡自动视为全软件源卡，无需人工迁移。
- 保留 GitHub 在线更新、SHA256、数据库/程序备份、文件校验与失败回滚机制。
