更新内容：
1. 2026091913 已发布并冻结；本次所有功能与修复进入 2026091914，不覆盖任何历史 Release Asset。
2. IPA 扫描改为严格 MySQL bt1a 引用工作集；删除无 MySQL 软件源时扫描整个 OpenList 根目录的 fallback。
3. OpenList 继续只负责文件访问、MD5、目录缓存和 HTTP Range；普通 MD5 扫描优先使用目录缓存，强制刷新目录独立执行。
4. Parser 固定每次后台解析 1 个 IPA，采用原子领取、needs_reparse 并发保护和 30 分钟失败退避。
5. 新增独立 fa_ipa_parse_cache，以 MD5 + 文件大小 + Parser Version 复用解析结果，并保留完整 metadata payload。
6. fa_ipa_metadata 收敛为当前 active workset，新增 referenced / needs_reparse；无引用且未绑定的历史记录可安全回收。
7. 修复 IPA 元数据“全部/已解析/待解析/失败”查询路径，count/rows 分离构造 Query，避免 ThinkPHP/PDO placeholder 复用问题。
8. 元数据刷新失败时明确显示旧数据状态；OpenList 停用后扫描、强刷、解析和连接测试均禁止，历史健康结果仅作为上次检查展示。
9. queued 且 heartbeat=0 的僵尸扫描任务可被恢复；后台 spawn 使用 CLI PHP 并校验子进程状态，降低 queued/0/0 假启动。
10. 新增 Phase 20 Workset MySQL57 Gate，真实 MySQL 5.7 连续执行最新迁移两遍并验证 workset/cache schema。
