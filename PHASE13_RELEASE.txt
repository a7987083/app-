ZONOE 软件源 Release 2026091607
版本：2026091607
基线：2026091606

更新内容：
1. Phase 15.3 将整站储存扫描从 PHP 递归 scandir/stat 改为后台 PHP CLI 调用系统 GNU find，高速采集路径、大小、mtime、inode。
2. 新增 runtime/storage 持久索引；打开更新运维中心直接读取上一次结果，不再因扫描而阻塞页面。
3. application/vendor/thinkphp/extend/addons/public assets/public static 使用目录快速 SHA256 指纹；与上次索引一致时整目录跳过详细扫描并复用统计。
4. “重新扫描全站”变成后台任务，新增扫描进度条，实时显示百分比、处理文件数和阶段。
5. “执行自动安全清理”变成后台任务，新增清理进度条，实时显示处理数、删除数和释放容量；结束后自动刷新索引。
6. 安全清理预览只读取索引，不再触发全站扫描；最大文件 TOP 50 改为扫描过程中限量维护，降低 PHP 内存和排序开销。
7. 保持原有保护策略：程序文件、public/uploads、日志、更新状态、符号链接与路径穿越不自动删除；备份和未知文件仍需人工确认。
8. 新增 Phase 15.3 PHP 7.0 合约/运行时回归，并强制 FastStorageManager 和 storage_worker 进入正式在线更新包。

配置要求：
- 推荐 GNU find、sort、sha256sum。
- PHP 需允许 exec、proc_open，并存在同版本 PHP CLI；如果被 disable_functions 禁用，后台会明确显示“系统扫描能力不可用”，不会回退为慢速 PHP 全站扫描。

兼容性：
- 兼容宝塔 PHP 7.0。
- 不修改数据库结构和授权数据。
- 不改变 appstore/appstore_v2、Nuosike 加密、UDID、卡密时长、黑名单和 transfer_count 语义。
- 保留 GitHub 在线更新、SHA256、备份、文件校验与回滚机制。
