ZONOE 软件源 Release 2026091704
版本：2026091704
基线：2026091703

更新内容：
1. 新增应用属性 renewal_entry，后台新增/编辑应用可标记为“续费入口”。
2. 续费入口复用客户端现有“解锁→输入卡密”流程，不新增客户端页面或新协议。
3. renewal_entry=1 的应用始终输出 lock=1、downloadURL=''，游客、全软件源卡和指定App卡均不能把它解锁为可下载应用。
4. 客户输入未使用卡密后继续使用现有 App::activateCode，根据当前客户端 UDID 一次性消费卡密并按 card_scope 叠加对应授权链时间。
5. 修复换绑记录“清空”按钮原先只重置搜索、不删除日志的问题。
6. 修复授权事件“清空”按钮原先只重置搜索、不删除日志的问题。
7. 两类日志清空均改为 POST + 二次确认，成功后返回实际删除条数；清空日志不修改卡密、当前授权有效期或换绑额度。
8. 新增 2026091704_renewal_entry.sql，兼容 MySQL 5.7，重复执行安全；旧应用默认 renewal_entry=0。
9. 新增 Phase17.3 PHP 7.0 契约/运行时测试和 MySQL 5.7 双执行迁移测试。
10. 在线更新清单补齐 category add/edit、authorization transfers/events 等本版本运行时文件。

数据库：
- fa_category 新增 renewal_entry tinyint(1) unsigned NOT NULL DEFAULT 0。
- 0=普通应用，1=续费入口。
- 迁移脚本：release/sql/2026091704_renewal_entry.sql。

- 保留 HTTPS、SHA256、数据库/程序备份、文件覆盖校验、失败回滚和真实 Release E2E。

兼容性：

- 不改变现有三种卡密用途、卡密一次性消费规则、授权时间定义、apiface 签名和授权叠加语义。
