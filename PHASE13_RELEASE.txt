更新内容：
1. 新增 IPA 数据中心：OpenList 数据源、分页扫描、增量/全量扫描、扫描队列、独立解析 Worker。
2. 新增 HTTP Range IPA/ZIP 解析，支持 XML/binary plist，避免为读取元数据下载整包 IPA。
3. 新增 Mach-O 深度索引：SHA256、arm64/x86_64 等 architectures、LC_ID_DYLIB/install_name。
4. 新增 IPA -> fa_category 手动 preview/apply 写回，后台 Worker 禁止自动写回。
5. 新增 Dylib 验证中心：Dylib 注册、版本策略、多 BundleID 绑定、验证日志、独立验证密钥。
6. 新增 Dylib 验证 API：UDID/卡密/黑名单/BundleID/版本/SHA256/HMAC/timestamp/nonce/短期 session。
7. 默认离线容忍 900 秒；失败动作与版本状态均由服务端策略控制，不在客户端写死。
8. 新增 Objective-C arm64 验证客户端，包含宿主 BundleID、自身 SHA256、HMAC、Keychain 离线缓存。
9. 新增 ipa:worker、ipa:parse-worker、ipa:maintenance 与 systemd 模板。
10. 新增 MySQL 5.7 / 100000 资产 / Worker contention / PHP 7.0 / iPhoneOS arm64 / OpenList HTTP 集成门禁。
