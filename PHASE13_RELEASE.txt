更新内容：
1. 基于 2026092427，仅修复 IPA Parser 启动链，不改 Parser V2 的 metadata / Range / MD5 / OpenList 数据逻辑。
2. 修复 PHP-FPM 环境下 IpaWorkerLauncher 直接使用 PHP_BINARY 的问题。PHP-FPM 下 PHP_BINARY 可能指向 php-fpm，而不是 CLI php，导致 `think ipa:parse-worker --scheduled` 被错误启动后立即退出。
3. 新增 CLI PHP 解析逻辑：优先当前 PHP 安装目录/bin/php、PHP_BINDIR/php、宝塔 `/www/server/php/<major><minor>/bin/php`，再回退 `/usr/bin/php` 与 `/usr/local/bin/php`。
4. 找不到可执行 CLI PHP 时返回 `cli_php_not_found`，不再把失败伪装成已正常调度。
5. 保留 2026092427 的应用内 Parser 触发、systemd 可选入口、MD5 metadata 复用、OpenList 目录缓存、256 KiB Range block cache、16 MiB 单 IPA 预算、30 分钟 parse_failed cooldown 与有界批次。
6. 保留 IPA 扫描、资产记录、搜索、删除、清空解析结果、OpenList 数据源、增量/全量扫描、现有后台 UI，以及其它软件源/卡密/Dylib 功能。
