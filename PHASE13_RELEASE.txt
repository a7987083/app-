ZONOE 软件源 Release 2026091606
版本：2026091606
基线：2026091605

更新内容：
1. Phase 15.2 将更新运维中心升级为全站文件/储存管理，扫描 ROOT_PATH 下全部普通文件。
2. 全站文件按核心程序、业务持久数据、缓存、日志、备份、临时文件、未识别文件分类统计，并展示网站总占用。
3. 自动安全清理只处理可重建缓存与明确临时文件，且跳过 1 小时内新文件。
4. ZIP/TAR/GZ/7Z/RAR/SQL/BAK 等备份和未识别文件进入人工确认区，可逐项勾选删除，但不会自动删除。
5. 服务端对人工删除路径再次分类并校验，程序文件、public/uploads、日志、更新任务状态、路径穿越和符号链接不会被删除。
6. 新增最大文件 TOP 50，快速定位高占用文件。
7. 新增 Phase 15.2 PHP 7.0 合约和运行时测试，并强制确认 SiteStorageManager 已进入正式在线更新包。

兼容性：
- 兼容宝塔 PHP 7.0。
- 不修改数据库结构和授权数据。
- 不改变 appstore/appstore_v2、Nuosike 加密、UDID、卡密时长、黑名单和 transfer_count 语义。
- 保留 GitHub 在线更新、SHA256、备份、文件校验与回滚机制。
