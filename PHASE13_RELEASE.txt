更新内容：
1. 新增后台“OC 工程生成”模块，直接读取当前软件源 ApiEndpointRegistry 作为接口元数据来源。
2. 支持生成前 Draft 编辑：工程名、类前缀、Base URL、最低 iOS、超时、User-Agent、接口启用状态、Path、Method、Auth 与说明均可在本次生成中调整，不回写线上 API 配置。
3. 新增配置校验与 config_hash 锁定；最终生成必须使用最近一次预览得到的 hash，避免“预览配置”和“实际生成配置”不一致。
4. 生成 Objective-C APIConfig、APIEndpoints、APIClient、GeneratedConfig.json、API_REFERENCE.md、INTEGRATION.md 与 generation-manifest.json。
5. 当前 ApiEndpointRegistry 未提供完整 Response Schema，因此 2407 不伪造 Objective-C Model；后续在响应结构元数据化后再生成 Models。
6. UDID、卡密、Token、HMAC 等敏感值不写死进生成源码，保留运行时参数/headerProvider 注入机制。
7. 最终 ZIP 写入 runtime/codegen 临时目录，使用随机下载 token、SHA256 和 1 小时过期时间，不写入持久业务配置。
8. 新增后台菜单与权限 SQL：release/sql/2026092407_oc_codegen.sql，支持 MySQL 5.7 重复执行。
9. 在线更新 manifest 已包含生成器核心、Controller、View 和 JS；SQL 继续由现有 build_online_update.php 自动收入 mysql/。
10. 新增 PHP 7.0 生成器 contract、Node JS syntax check、在线更新 ZIP 内容检查、MySQL 5.7 双迁移验证。
