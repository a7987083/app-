更新内容：
1. Dylib 验证中心职责收敛为 API 提供方：验证接口、HMAC、错误码、运行配置、通知/更新数据与验证日志；客户端 UI 不属于验证中心。
2. 新增 DylibApiContract，集中记录真实请求字段、返回字段、v1/v2 canonical、action 和 result code。
3. 保持既有字符串 code 协议，不新增破坏兼容性的数字错误码。
4. Objective-C Generator 升级到 2.2.0，明确定位为 API 测试/参考代码生成器。
5. 生成包新增 API_REFERENCE.md、ERROR_CODES.md、EXAMPLES.md；实际客户端可以不使用生成 OC，直接按 API 文档自行实现。
6. 后台“API 接入说明”增加接口、请求参数、返回字段、错误码、签名和接入原则。
7. 客户端业务判断应使用 ok + code；message 可作为服务器提示展示，但不得依赖 message 文本判断业务状态。
8. notice / app_update / permissions / access_level 均为 API 返回数据，如何显示由客户端工程自行决定。
9. 在线更新 manifest 新增 application/common/library/Ipa/DylibApiContract.php。
10. 现有 v1/v2 HMAC wire contract、数据库结构和 legacy Index API 均保持兼容。
