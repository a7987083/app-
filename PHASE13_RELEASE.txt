更新内容：
1. 直接以正式版 2026092428 为基线重新开发，不继承 2429 的精简实现。
2. 完整保留 2428 Dylib 验证中心原有 API、后台管理、版本管理、通知、验证日志、Runtime Config、Codegen、API 文档下载、Legacy API URL、App Identity、权限、App Update、offline grace、session token 与 SHA256 校验。
3. 删除客户端 Verify Secret / verify_secret_ciphertext / HMAC 请求认证，不再把全局共享 Secret 写入生成代码。
4. 新增 Protocol v3：一次性 Challenge + 每设备 P-256 Keychain 密钥 + ECDSA-SHA256 设备证明；首次公钥登记必须使用已激活且绑定同一 UDID 的现有卡密。
5. Runtime Config 改为服务器 RSA-2048/SHA-256 签名；客户端仅内嵌服务器公钥和 Key ID。
6. 服务器签名私钥改存 runtime 私有文件，不再依赖 signing_private_key_ciphertext 等数据库字段，避免生产 schema 半升级导致 fields not exists。
7. 保留原 8 个 API 入口，并新增 POST /index/dylib_verify/challenge；/authorization、/appstore、/index/index/apiface、/index/index/dylib、/unbind、/unbind/query、Runtime Config、Verify 均继续存在。
8. 新增 2026092430 幂等 MySQL 5.7 migration：创建 device key/challenge 表、移除旧 Verify Secret 字段和 dylib_nonce 表，不创建数据库签名私钥字段。
9. 在线更新包加入 DylibDeviceAuthService.php、DylibSigningKey.php 与 2026092430 migration。
