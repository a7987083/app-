ZONOE 软件源 Release 2026091701
版本：2026091701
基线：2026091611

更新内容：
1. 解锁码激活成功响应新增 expire、ts、nonce、sign 四个字段，原 code/msg 和三种卡密权限逻辑保持不变。
2. sign 使用 HMAC-SHA256，签名原文为 udid|expire|ts|nonce；nonce 使用 8 字节安全随机数。
3. 系统配置新增 unlock_sign_key，后台显示“解锁签名KEY”；管理员填写什么值，服务端就使用什么值。
4. KEY 不写入 GitHub 源码、不返回解锁接口、不写入授权事件日志。
5. unlock_sign_key 留空时，首次解锁前自动生成 32 字节随机 KEY 并写回服务器配置，避免升级后因未配置 KEY 中断解锁。
6. 全软件源卡、仅验证卡、指定App卡统一返回 expire/ts/nonce/sign，并保留各自原成功提示。
7. 在线更新包新增 2026091701_unlock_signing.sql，只新增配置项且不会覆盖已有 KEY，脚本可重复执行。
8. 新增 Phase17 协议契约测试和 MySQL 5.7 配置迁移测试。

兼容性：
- 兼容宝塔 PHP 7.0、MySQL 5.7。
- 原有成功状态码继续使用 code=0。
- 不改变卡密字符串格式、日/周/月/季/年时长、card_scope、fa_kami_app、权限链叠加和换绑逻辑。
- 保留 GitHub 在线更新、SHA256、数据库/程序备份、文件校验与失败回滚机制。
